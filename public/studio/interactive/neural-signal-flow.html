Predict: change one input. Which hidden neurons respond most? Orange dots show positive weighted contributions; blue dots show negative contributions. Their sizes indicate magnitude, not probability.

What is calculated?

This small, untrained network computes h = tanh(W₁x + b₁), then y = W₂h + b₂. Each hidden neuron sums its incoming contributions before applying tanh. The outputs are raw scores. The animation changes presentation time, not the computed answer. New weights creates a different network; it does not train the model.
