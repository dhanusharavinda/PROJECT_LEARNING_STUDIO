# Learning Studio

Learning Studio extends LearnHarness with an integrated ManimGX blackboard for students learning difficult concepts, initially AI engineering and interview preparation.

The user approved a separate Windows Electron application. Synapse remains the notebook and is not modified. Keep LearnHarness attribution, its teaching flow, existing graph, practice, settings, keyboard controls, and visual system. Add compact animation cards in lessons and a guided DeepSeek setup. Preserve upstream licenses. Do not publish to upstream update feeds.

The teacher explains immediately, establishes prerequisites, asks predictions, requests a short contextual animation when useful, and follows with an understanding check or coding exercise. A watched animation is not proof of learning. Static figures and interactive demos remain available alongside animations.

Use the DeepSeek Flash 1017 API as the user-applied recommended setup, with Pro available for harder lessons. Speed, precise explanations, and quality take precedence over using free models. The user will add an API key later. Never fabricate successful live provider tests or make cloud calls without the configured key. Retain existing provider choices and local endpoint support.

ManimGX renders locally from a bounded structured scene plan. Preserve source plans and exported media, show failures clearly, and allow retry and cancellation. Do not execute arbitrary model-generated Python with access to personal files or credentials. No automatic cloud narration or paid speech generation.

Export readable lesson Markdown on explicit click. Animation downloads remain separate portable files. Synapse receives only material the user chooses to save; neither application silently rewrites the other's notes or graph.

Operate mode: compact controls, existing typography and theme tokens, accessible playback, readable diagrams, responsive layouts, no decorative dashboards. Never use em dashes in new copy.
